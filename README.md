# NOSTALJII 2007

### ▶ ブラウザで遊ぶ： https://katomi95.github.io/nostaljii2007/

**忘れようとしても、思い出せない。**

1990年代初頭のサスペンスADV風・短編ミステリーアドベンチャー（パロディ作品）。
ブラウザだけで動作します。プレイ時間およそ15〜20分。

---

## あらすじ

2007年7月9日。豪華客船〈ノスタル爺号〉が航海中に爆発する。
船内放送から流れる犯人の要求は「3時間以内に "あの日のアレ" を渡せ」。
ただし犯人自身も、それが何だったかを覚えていない。

爆発現場に名刺が落ちていたというだけの理由で犯人扱いされた日本人会社員
ヤマナ・カスケは、自分が爆弾を仕掛けていないという記憶すら確かではないまま、
何ひとつ覚えていない乗客たちの尋問を始める。

---

## 遊びかた

- クリック / タップ / スペースキー・Enterキー で会話を送る
- 送り中にもう一度押すと、その行を最後まで表示
- 尋問中は **記憶姿勢**（覚えている / 覚えていない / 覚えているふり）を選択
- 画面右の **I-CAS** ウィンドウには、主人公の本音が表示される
- 右下 `♪` で環境音のオン／オフ、`TITLE` でタイトルへ戻る

音はページ内の操作（STARTボタン）をきっかけに鳴り始めます（ブラウザの自動再生制限対応）。

---

## ファイル構成

```
index.html    画面構造
style.css     セピア調・CRT演出・レスポンシブ
story.js      シナリオデータ（全5シーン・選択肢・分岐）
script.js     ADVエンジン＋SVG背景／立ち絵＋Web Audio環境音
```

外部ライブラリ・外部素材は一切使用していません。
背景・人物・効果音はすべて SVG と Web Audio API で生成しています。
